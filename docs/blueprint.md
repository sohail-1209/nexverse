# **App Name**: NExVERSE

## Core Features:

- User Authentication: User authentication and profile management with Firebase Auth, enabling personalized content and saved data.
- Subject-Wise Repository: Organize and display exam answers by subject, question category, and type (2/5/10-mark).
- Content Management: Enable users to upload new answers (text or file), edit/delete their uploads, and bookmark or save answers.
- Chat Interface: Chat UI for user to input questions and display answers.
- Search & Filter: Search answers by title, tags, or subject, and filter by subject, marks, or tags.
- Bookmarks Management: Display and manage all saved answers in a dedicated "My Bookmarks" page for quick access.
- Admin Moderation: Simple role-based access control with admin privileges to mark answers as verified and delete inappropriate content.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey knowledge and focus.
- Background color: Light gray (#F5F5F5) for a clean and readable interface.
- Accent color: Teal (#009688) for highlights and interactive elements.
- Headline font: 'Poppins' (sans-serif) for a modern, precise feel.
- Body font: 'Inter' (sans-serif) for readability.
- Use clear, minimalist icons to represent subjects, categories, and actions.
- Subtle animations for feedback and transitions to enhance usability.
